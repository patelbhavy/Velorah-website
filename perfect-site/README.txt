PERFECT SITE - WampServer64 setup (Edit Mode Removed)
1. Unzip this folder so you have C:\\wamp64\\www\\perfect-site\\index.html
2. Start WampServer (green icon), then open http://localhost/perfect-site/
3. The website runs without the Edit Mode button, keyboard shortcut, editor panel, or edit-save endpoint.
Needs internet for videos, images and Google Fonts (they load from the original URLs).
